# Console Task Manager

A simple Python console application to manage tasks with priorities.

---

## Features
- Add tasks with a name and priority (High, Medium, Low)  
- View all tasks in a numbered list  
- Delete tasks by number  
- Easy-to-use console interface  

---

## How to Run
1. Make sure you have **Python 3** installed on your system.  
2. Clone the repository or download the `app.py` file.  
3. Open a terminal and navigate to the folder containing `app.py`.  
4. Run the program:
```bash
python task_manager.py
